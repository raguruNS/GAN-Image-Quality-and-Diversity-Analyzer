# GAN Image Quality and Diversity Analyzer

## 1. Project Overview

The **GAN Image Quality and Diversity Analyzer** is a Python-based web application designed to evaluate the visual quality, uniqueness, similarity, and diversity of images generated by Generative Adversarial Networks (GANs).

The project uses a pretrained GAN to generate images without training a model from scratch. Users can also upload existing generated images and analyze them through an interactive Streamlit interface.

The application identifies duplicate images, compares visual similarity, displays image-quality statistics, visualizes diversity, and generates an automatic analysis report.

## 2. Objectives

- Evaluate images generated by a pretrained GAN.
- Display generated images in an interactive gallery.
- Identify exact duplicate and potentially similar images.
- Analyze basic image-quality indicators.
- Visualize the diversity of generated samples.
- Detect possible repetitive patterns that may indicate limited diversity.
- Generate downloadable reports for further analysis.

## 4. Features

### Image Generation
- Load a compatible pretrained GAN model.
- Generate images using random latent inputs.
- Configure the number of generated samples.
- Use a random seed for reproducibility where supported.

### Image Gallery
- Display generated images in a grid.
- Upload multiple existing images.
- Support ZIP files containing images.
- Inspect image dimensions and visual appearance.

### Image Quality Analysis
- Validate image files.
- Analyze dimensions, brightness, and contrast.
- Calculate a basic sharpness estimate.
- Display image-level statistics.

### Duplicate and Similarity Analysis
- Detect exact duplicate files using SHA-256 when original file bytes are available.
- Calculate perceptual difference hashes (dHash).
- Compare images using pairwise similarity scores.
- Identify potentially near-duplicate image pairs.

### Diversity Visualization
- Display a pairwise similarity histogram.
- Calculate the number of unique perceptual hashes.
- Display duplicate and similarity statistics.
- Generate a heuristic diversity report.

### Report Generation
- Display a summary of analysis results.
- Export image statistics to CSV.
- Export pairwise similarity results to CSV.

## 6. Installation and Setup

### Prerequisites

- Python 3.10 or newer recommended.
- Visual Studio Code or another Python editor.
- Internet access for downloading pretrained model files.
- GPU is optional; CPU execution may be slower.

### Step 1: Download the Project

Download or clone the project repository and open its folder in Visual Studio Code.

### Step 2: Create a Virtual Environment

Open the terminal in the project directory and execute:

```bash
python -m venv .venv
```

Activate the environment on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

### Step 3: Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal. The default is usually:

```text
http://localhost:8501
```

## 8. Evaluation Metrics

### Exact Duplicate Detection

SHA-256 hashes are used to determine whether original files have identical contents. Visually identical images saved with different file encodings may have different SHA-256 hashes.

### Perceptual Similarity

Difference hashing (dHash) captures simple visual structure. The pairwise similarity is calculated as:

\[
S(A,B)=1-\frac{d_H(A,B)}{64}
\]

Where:

- \(S(A,B)\) is the estimated similarity.
- \(d_H(A,B)\) is the Hamming distance between two 64-bit hashes.

A higher score indicates greater similarity under this particular hash representation.

### Brightness and Contrast

Grayscale pixel statistics are used to estimate mean brightness and contrast variation.

### Sharpness Estimate

A Laplacian-variance-based statistic provides a basic indication of edge detail. High values can also result from noise or complex textures.

### Diversity Assessment

The application combines mean pairwise similarity and the ratio of unique perceptual hashes to produce a simple assessment:

- **Appears diverse:** Samples differ under the chosen comparison method.
- **Some repetition detected:** Similar visual structures appear among samples.
- **Highly repetitive:** The sample set shows substantial repetition under the heuristic.

These labels are indicative only and do not establish whether the GAN has experienced mode collapse.

## 10. Limitations

- The application does not train a GAN from scratch.
- Pretrained model availability depends on the external repository and model weights.
- dHash measures simple visual similarity rather than semantic similarity.
- Basic brightness, contrast, and sharpness statistics do not fully measure realism.
- A diverse image set may still contain unrealistic images.
- Similarity-based repetition is not definitive proof of mode collapse.

For research-grade evaluation, metrics such as **FID (Fréchet Inception Distance)**, **KID (Kernel Inception Distance)**, precision/recall for generative models, or LPIPS can be considered with appropriate feature extractors and reference data.

## 12. Conclusion

The GAN Image Quality and Diversity Analyzer provides an interactive way to inspect generated images and assess their visual similarity and diversity without training a GAN from scratch.

By combining pretrained model inference, image preprocessing, duplicate detection, statistical analysis, visualizations, and downloadable reports, the project demonstrates a practical workflow for evaluating GAN-generated samples.

The application is intended as an educational and exploratory tool. Its lightweight metrics provide useful diagnostics but should not be treated as definitive measures of image realism or generative-model performance.
